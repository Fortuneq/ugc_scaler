# ugc_scaler

An early-stage React project. At the moment it contains only the Create React App scaffold (React 19).

```mermaid
flowchart LR
    A[npm start] --> B[Dev server :3000]
    C[npm run build] --> D[Optimised bundle in build/]
    E[npm test] --> F[Jest + Testing Library]
```

## Run locally

```bash
npm install
npm start      # http://localhost:3000
npm test
npm run build  # production build in build/
```
